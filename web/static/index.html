    Télécharger le CSV

    Vue d'ensemble de chaque colonne : type détecté, cellules vides, valeurs distinctes, extrêmes et valeurs les plus fréquentes.

    Cochez les colonnes à conserver, réordonnez-les avec les flèches et renommez-les si besoin.

    Trie les lignes sur une ou plusieurs colonnes (la première est prioritaire). Les cellules vides sont toujours placées à la fin. Fonctionne aussi sur des fichiers plus gros que la mémoire.

    Repère les lignes en double selon certaines colonnes (ou la ligne entière) pour les supprimer ou les isoler.

    Colonnes formant l'identifiant

    Aucune colonne cochée : deux lignes sont des doublons si toutes leurs cellules sont identiques.

    Résultat souhaité

    Conserve uniquement les lignes qui respectent les conditions.

    Enchaînez des opérations de nettoyage et de calcul ; elles sont appliquées dans l'ordre, en un seul passage.

    Empile les lignes de plusieurs fichiers dans un seul fichier. Cochez les fichiers dans l'ordre souhaité.

    Fichiers à fusionner

    Alignement des colonnes

    Associe les lignes de deux fichiers dont les colonnes clés ont les mêmes valeurs. Pour les gros volumes, placez le plus petit fichier à droite (il est chargé en mémoire).

    Colonnes de découpage

    Interrogez vos fichiers en SQL (dialecte SQLite). Chaque fichier est une table dont le nom figure ci-dessous ; cliquez sur un nom pour l'insérer. Les noms de colonnes contenant des espaces ou accents s'écrivent entre guillemets doubles.

    Tables disponibles

    Aide et fonctions disponibles
    • Toutes les valeurs sont du texte. Pour calculer, utilisez num(colonne) qui comprend « 1 234,5 » : SUM(num(montant)), WHERE num(prix) > 100.
    • date_iso(colonne) convertit « 31/12/2024 » en « 2024-12-31 » pour trier ou comparer des dates.
    • sans_accents(colonne) renvoie la valeur en minuscules sans accents.
    • colonne REGEXP '^(Paris|Lyon)$' teste une expression régulière.
    • Jointures : SELECT * FROM a JOIN b ON a.id = b."id client". Seules les requêtes de lecture sont acceptées.

    Une recette enregistre une suite d'opérations (colonnes, tri, doublons, filtre, nettoyage) pour la rejouer sur de nouveaux fichiers. Pour en créer une, appliquez vos opérations à un fichier puis enregistrez le résultat comme recette. Les recettes sont conservées entre deux démarrages.
